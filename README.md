# Pensum Manager

Sistema de gestión de trayectoria académica universitaria.

## Descripción

Pensum Manager te permite digitalizar tu pensum universitario, visualizar tu progreso académico y gestionar prerrequisitos de manera inteligente.

## Características

- ✅ **Control de progreso**: Marca materias aprobadas y visualiza tu avance
- 🔒 **Validación inteligente**: Verificación automática de prerrequisitos
- 📊 **Visualización clara**: Malla curricular con sistema de colores
- ☁️ **Sincronización en la nube**: Accede desde cualquier dispositivo
- ⚡ **Rendimiento óptimo**: Carga rápida y responsive
- 🛡️ **Datos protegidos**: Información cifrada y segura

## Tecnologías

- React 18 + TypeScript
- Vite
- TailwindCSS
- Shadcn/UI
- Supabase (Backend & Auth)
- React Query

## Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Compilar para producción
npm run build
```

## Variables de Entorno

Crea un archivo `.env` con:

```
VITE_SUPABASE_URL=tu_url_de_supabase
VITE_SUPABASE_ANON_KEY=tu_anon_key
```
